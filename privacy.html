Privacy Policy

Last updated: October 12, 2026

This policy covers the WhyStory uploader ("the app"), a private tool that uploads videos to the WhyStory YouTube channel (@WhyStoryDaily) using YouTube API Services.

YouTube API Services

The app uses YouTube API Services. By using the app's YouTube features you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the app

The app is used only by the owner of the WhyStory channel, on the owner's own computer. It is not offered to the public and has no other users.

What data the app accesses

  • Google sign-in authorization. When the channel owner signs in with Google, the app receives an OAuth token with two permissions: upload videos (youtube.upload) and view the channel's basic details (youtube.readonly), used only to confirm which channel it is connected to.
  • Upload results. After each upload, YouTube returns the new video's ID and privacy status, which the app records in a local log so it doesn't upload the same video twice.

The app does not access, collect or store data about viewers, subscribers, comments, other channels or any other YouTube users.

How the data is used and stored

  • The OAuth token is stored only on the channel owner's computer and is used only to upload the channel's own videos and to confirm the connected channel.
  • The upload log (video IDs, titles, dates) is stored only on the channel owner's computer.
  • No data is sold, shared with third parties, used for advertising, or sent to any server other than Google's own APIs.

Cookies and tracking

The app does not use cookies. This website does not use cookies, analytics or trackers.

Deleting data and revoking access

Access can be revoked at any time from the Google Account security settings page at https://security.google.com/settings/security/permissions. Deleting the app's local token file and upload log removes all stored data. Any data received from YouTube API Services is deleted within 30 days if access is revoked or the app is no longer used.
