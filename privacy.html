Privacy Policy

Last updated: October 12, 2026 (added channel analytics and TikTok drafts)

This policy covers the WhyStory uploader ("the app"), a private tool that uploads videos to the WhyStory YouTube channel (@WhyStoryDaily) using YouTube API Services.

YouTube API Services

The app uses YouTube API Services. By using the app's YouTube features you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

TikTok

The app can also send WhyStory's own finished videos to the channel owner's TikTok account as drafts, using TikTok's Content Posting API. It never publishes on TikTok by itself: the owner opens each draft in the TikTok app, chooses its caption and settings, and posts it. Use of this feature is subject to the TikTok Terms of Service and the TikTok Privacy Policy. With the owner's permission, the app receives a TikTok access token with two permissions: basic profile info (user.info.basic, used only to confirm which account is connected) and upload videos as drafts (video.upload). The token and a log of sent drafts are stored only on the owner's computer. No data about TikTok viewers or other accounts is accessed. Access can be revoked at any time in the TikTok app under Settings and privacy → Security → Manage app permissions.

Who uses the app

The app is used only by the owner of the WhyStory channel, on the owner's own computer. It is not offered to the public and has no other users.

What data the app accesses

  • Google sign-in authorization. When the channel owner signs in with Google, the app receives an OAuth token with three permissions: upload videos (youtube.upload), view the channel's details and video list (youtube.readonly), and view YouTube Analytics reports for the channel (yt-analytics.readonly).
  • Upload results. After each upload, YouTube returns the new video's ID and privacy status, which the app records in a local log so it doesn't upload the same video twice.
  • Channel statistics. Once a day the app reads the WhyStory channel's own aggregate statistics (views, watch time, average percentage viewed, likes, shares, comment counts and subscriber changes, overall and per video) to produce a private performance report for the channel owner. These are aggregate numbers only and contain no information about individual viewers.

The app does not access, collect or store data about viewers, subscribers, comments, other channels or any other YouTube users.

How the data is used and stored

  • The OAuth token is stored only on the channel owner's computer and is used only to upload the channel's own videos and to confirm the connected channel.
  • The upload log (video IDs, titles, dates) and the daily performance reports are stored only on the channel owner's computer. Statistics retrieved from YouTube API Services are refreshed daily, and stored copies older than 30 days are refreshed or deleted.
  • No data is sold, shared with third parties, used for advertising, or sent to any server other than Google's own APIs.

Cookies and tracking

The app does not use cookies. This website does not use cookies, analytics or trackers.

Deleting data and revoking access

Access can be revoked at any time from the Google Account security settings page at https://security.google.com/settings/security/permissions. Deleting the app's local token file and upload log removes all stored data. Any data received from YouTube API Services is deleted within 30 days if access is revoked or the app is no longer used.
